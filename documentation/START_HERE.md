## 💾 Data Storage Explanation

### How Data is Saved
When you add a member or change settings:
1. You fill a form
2. Click Save/Add
3. JavaScript converts data to JSON
4. Stores in browser's LocalStorage
5. Data automatically loads when you return

### No Server Needed
- Data stays in your browser
- Private and secure locally
- Works without internet
- Lost if you clear browser data (use export to backup)

### Backup Your Data
From the Settings page:
1. Click **Settings**
2. Go to **System** tab
3. Click **Export Data**
4. Download the JSON file
5. Save it somewhere safe

To restore from backup:
1. Go to **Settings** → **System**
2. Choose the JSON backup file
3. Click **Import Data**
4. Your data is restored!
